# Skill Sync

A skill-sharing platform where people can offer skills, find people to learn
from, request sessions, message each other, and leave reviews.

## Project structure

- `client/` — React + Vite frontend
- `server/` — Node.js + Express backend
- `docs/api-contract.md` — API paths, data formats, and workflow rules

## Requirements

- Node.js and npm
- MongoDB
